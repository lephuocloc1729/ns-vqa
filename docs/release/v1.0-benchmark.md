# SignCite v1.0-benchmark: the frozen benchmark system

This release marks the code that produced SignCite's private-test benchmark: the frozen **phase52** system
([`eval/frozen_phase52.json`](https://github.com/lephuocloc1729/ns-vqa/blob/v1.0-benchmark/eval/frozen_phase52.json)). The tag `v1.0-benchmark` points at `4e71a18`.

The private test was run three times on this system, at three commits whose `vqa/`, `kb/`, `prompts/`, `app/`
and `pyproject.toml` are identical:

| Run | Commit | Run id |
|---|---|---|
| 1 | `3f45ba6` | `a51605785ace` |
| 2 | `20f5926` | `3163188d23b7` |
| 3 | `4e71a18` (the tag) | `e243362cb98e` |

All three run records ([`eval/private_ran.json`](https://github.com/lephuocloc1729/ns-vqa/blob/02ed7a1/eval/private_ran.json), [`eval/private_ran_2.json`](https://github.com/lephuocloc1729/ns-vqa/blob/02ed7a1/eval/private_ran_2.json), [`eval/private_ran_3.json`](https://github.com/lephuocloc1729/ns-vqa/blob/02ed7a1/eval/private_ran_3.json)) name the same
freeze record, sha256 `22004c43b67d6cc2b1c00df80a00cd87e6241bcc1f8eaf2b307ac698c976fd69`.

Later commits on `main` (the demo, the API and UI work, and the post-benchmark D.14 lane fix `05e4b3b`) were never
scored on the private test.

## Results

The benchmark is the private test of VLSP 2025 MLQA-TSR (Natural QA version): 146 questions on 104 photos, run
3 times on the frozen system, every answer graded by hand.

| System | Private test |
|---|---|
| **V2: rules + RAG fallback** | **82.2%** (sd 1.8 over 3 runs) |
| V1: rules only | decides 66.9% of the questions, at 82.3% |
| RAG alone | 81.5% (119 of 146, hand-graded; judge 79.2%) |
| Baselines LowCost and LexiSignVQA | about 78% |

- On the public test (100 questions) V2 scores 84.5%.
- Every rules answer comes with a proof and law citations that cannot contradict it, and the system answers
  "undecided" instead of guessing when a fact is missing.

The full record of every step and number is [`docs/status.md`](https://github.com/lephuocloc1729/ns-vqa/blob/02ed7a1/docs/status.md).

## Reproducing

See "Reproducing the numbers" in [`README.md`](https://github.com/lephuocloc1729/ns-vqa/blob/02ed7a1/README.md#reproducing-the-numbers). In short:

- [`eval/freeze.py`](https://github.com/lephuocloc1729/ns-vqa/blob/v1.0-benchmark/eval/freeze.py) `check --profile phase52` checks that a checkout matches the frozen system.
- The private and public runs need the VLSP 2025 dataset (not included, see below) and an Anthropic API key;
  every paid script has a spend cap.
- The RAG fallback's code is not in this tag. It was imported into the repository later the same day and lives
  on `main` in [`services/rag/`](https://github.com/lephuocloc1729/ns-vqa/tree/02ed7a1/services/rag), byte-identical to the code that made the RAG predictions
  ([`services/rag/ORIGIN.md`](https://github.com/lephuocloc1729/ns-vqa/blob/02ed7a1/services/rag/ORIGIN.md): `trafficvqa-rag@a081015`, now `4a5c81c`). Its runtime files are listed with their
  sha256 in [`services/rag/assets_manifest.json`](https://github.com/lephuocloc1729/ns-vqa/blob/02ed7a1/services/rag/assets_manifest.json).

## Models and runtime assets

### The rules system's own artifacts

The rules side has no trained weights. Its model is its knowledge base and its prompts, all in the tag and pinned
by sha256 in the freeze record:

- the sign catalog and the Prolog rules, each citing its law article ([`kb/`](https://github.com/lephuocloc1729/ns-vqa/tree/v1.0-benchmark/kb));
- the versioned prompts and few-shot examples ([`prompts/`](https://github.com/lephuocloc1729/ns-vqa/tree/v1.0-benchmark/prompts));
- the freeze record that pins the models, prompts, rule code and switches ([`eval/frozen_phase52.json`](https://github.com/lephuocloc1729/ns-vqa/blob/v1.0-benchmark/eval/frozen_phase52.json)).

The gold annotations made for evaluating it are in the tag too ([`data/annotations/`](https://github.com/lephuocloc1729/ns-vqa/tree/v1.0-benchmark/data/annotations)): sign labels
and query programs keyed by image or question id, with no images and no dataset question text.

## What is not in this release, and why

- **The VLSP 2025 dataset** (images, questions, answers, the law corpus and its figures). It is not ours to
  redistribute; the VLSP data agreement applies. This includes the resized law figures the scene prompt uses
  (`prompts/scene/<version>/pictograms/`): only their manifest, with sha256, is in git.
- **Private-test answers and anything derived from them question by question.** Only aggregate scores are
  published. The run records in `eval/` hold only run ids, commits, hashes and spend.
- **The owner's grading sheets** (`owner_grading*.csv`): they hold gold answers and per-question grades.
- **The scene cache, the private-run replay records and the RAG answer cache:** model outputs per image and
  question, kept out of git.
- **The RAG asset bundle** (the law index, train captions and embeddings, cached query captions and embeddings):
  built from the dataset, so it stays in a private store. `services/rag/assets_manifest.json` lists every file
  with its sha256.
- **Model weights:** public upstream, linked in the table above with their revisions and hashes.
- **API keys and tokens:** never in the repository. Runs read `ANTHROPIC_API_KEY` from the environment.
